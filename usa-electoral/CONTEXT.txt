WHAT IT IS
----------
A single self-contained HTML page (index.html: inline CSS + JS, no build step, no
dependencies except the Libre Franklin Google Font). It draws election results as
square cartograms, NYT-style: one square per electoral vote / seat.

  USA  - President (2024 electoral college, Harris 226 vs Trump 312)
       - Senate and House (one shared "chamber" map that animates between the two)
       - Governors
  India - Lok Sabha (543 seats, currently all neutral grey; no party results yet)

UI: race toggle (pill tabs with a sliding thumb) top-left, country picker
(flag + name dropdown) top-right, tally numbers + bar with majority marker, map,
legend. URL hash selects the race (#president, #senate, #house, #governors,
#loksabha). Always light/white theme (color-scheme: light).


CODE MAP (index.html, top to bottom)
------------------------------------
CSS :root tokens: --dem --rep --flip --dflip --ind --house --seat-empty --muted ...
STATES / DEM / FLIP / PRES_LABELS - President map: each state as rows
    [row, firstCol, lastCol]; DEM = states won by Harris; FLIP = flipped to Trump
    (drawn hatched). ME-2 and NE-2 split votes are special-cased in drawPresident.
CHAMBER - House + Senate, one object per state:
    s state, c House squares [x,y,isDem,flipped], o two Senate seat squares,
    p Senate seat parties (d/r/i), f index of a Republican Senate pickup, h label.
S=20 (pixels per square), el(), hatches(), square(), label() - shared helpers.
drawPresident / drawChamber / setViewBox / countTo / setChamber - USA maps + tally.
INDIA - Lok Sabha tile map:
    [code, name, [[x,y],...seat squares], [labelX, labelY, inside?, anchor]]
    coordinates in square units; label y is the text's vertical centre
    (svg text uses dominant-baseline:central). drawIndia computes the viewBox
    from squares + an estimated label width.
Race toggle (show, moveThumb, panelOf, countryOf, lastRace) and Country picker
    (setCountryUI, openMenu, choose; keyboard accessible listbox).


DESIGN RULES THE OWNER HAS ASKED FOR
------------------------------------
- Clean NYT-like look: white background, Libre Franklin, muted grey labels.
- One square = one seat / vote. Squares have a 1px white stroke.
- India tile map (agreed 2026-10-09):
  * No geographic outline / land shape behind the squares - squares only.
  * Every state is ONE solid, edge-connected block: no holes, no stray squares.
  * Neighbouring states are separated by exactly one empty square (no touching,
    not even at corners), and pulled as close together as that allows, so the
    whole thing reads as the outline of India. The US map felt slightly too loose.
  * Specific shapes requested:
      J&K: row of 3 over row of 2; Ladakh sits diagonally off J&K's top-left.
      Himachal Pradesh: 2x2 square (4 seats).
      Maharashtra: heavy bottom-left, tapering upward, top-right step overhang.
      Karnataka: pointed (single-square) top.
      Odisha: tapers downward, with a 2x2 lobe pulled to the bottom-left.
  * Big states labelled inside; small states/UTs labelled beside the block.
    Chhattisgarh is labelled "C.G." (full name does not fit 3 squares wide).
