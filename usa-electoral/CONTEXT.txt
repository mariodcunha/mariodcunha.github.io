WHAT IT IS
----------
A single self-contained HTML page (index.html: inline CSS + JS, no build step, no
dependencies except the Libre Franklin Google Font). It draws election results as
square cartograms, NYT-style: one square per electoral vote / seat.

  USA   - President (2024 electoral college, Harris 226 vs Trump 312)
        - Senate and House (one shared "chamber" map that animates between the two)
        - Governors
  India - Lok Sabha 2024 (543 seats) coloured by alliance, with a small
          Seat share / Vote share toggle (see LOK SABHA 2024 RESULTS)

UI: race toggle (pill tabs with a sliding thumb) top-left, country picker
(flag + name dropdown, USA / India) top-right, tally numbers + bar with majority
marker, map, legend. Switching country swaps the visible tabs (USA: President,
Senate, House, Governors; India: Lok Sabha) and remembers the last race per
country. URL hash selects the race (#president, #senate, #house, #governors,
#loksabha). Always light/white theme (color-scheme: light).

INDIA MAP (current = owner's Figma tile map, re-imported 2026-10-09)
--------------------------------------------------------------------
The owner REJECTED the geographic re-packing (Appendix C) and asked to follow the
Figma frame exactly. Imported three times so far (latest 2026-10-09, frame now
4115 x 4655 px; centre states moved: MP, CG, OD, JH, TS). Source of truth = Figma node 3465:25773 (see header). The
frame was edited by the owner after the first import (tighter layout,
Uttarakhand 3 over 2), so ALWAYS re-fetch it rather than reusing old data.

Data: const INDIA = [[code, name, cells, [labelX, labelY, anchor]], ...]
    code   two-letter state/UT code (UP, MH, WB, ... DD = DNH & Daman-Diu)
    name   label text
    cells  [[x, y], ...] top-left corner of each seat square, in square units
           (multiply by S=20 for SVG units). Values are fractional: every state
           block keeps its exact Figma position, and blocks are not on one shared
           grid (each has its own sub-square offset). Inside a state the squares
           are on a whole-unit grid.
    label  [x, y, anchor]; anchor "middle" | "start" | "end".
Seat counts (total 543): UP 80, MH 48, WB 42, BR 40, TN 39, MP 29, KA 28, GJ 26,
    RJ 25, AP 25, OD 21, KL 20, TS 17, AS 14, JH 14, PB 13, CG 11, HR 10, DL 7,
    JK 5, UK 5, HP 4, GA 2, AR 2, MN 2, ML 2, TR 2, DD 2, and 1 each for LA, CH,
    SK, NL, MZ, PY, AN, LD.
Seat counts are verified: squares per state == the counts above (36 states/UTs,
    543 total, no duplicate squares). History by election: see LOK SABHA SEATS
    BY ELECTION below.
Label names: full names for most; shortened: J.&K., Himachal, W. Bengal, C.G.
    (Chhattisgarh), Andhra, Arunachal, A.&N. Islands, DNH-DD (Dadra & Nagar
    Haveli and Daman & Diu; owner asked for "DNH-DD").
Labels: SMALL on purpose (shared svg.map text style, 11 SVG units = ~7.7px on
    screen at 940px wide). The owner said small is fine as long as names never
    cross each other or a square. Placement (done offline, in square units):
    try centred above the block's top row (0.42 / 0.7 / 1.0 up), then below the
    bottom row, shifting sideways by up to 2 squares, then beside the block
    (start/end anchored); first spot whose text box (measured width at 11px,
    0.59 tall) keeps 0.08 clear of every square and 0.2 clear of every placed
    label wins. Biggest states are placed first. Verified in the browser: no
    overlaps, nothing clipped.
No hover effect: the owner tried one (name darker/bigger on hover) and asked
    for it to be removed - names just stay small and static.
Drawing: squares are <rect class="seat-sq"> (fill --seat-empty #d3d3d3, 1px
    white stroke); no outlines. viewBox fitted to squares plus approximate
    label extents (name.length * 0.32 units wide).
The earlier "same on-screen size as the House labels" sizing (--label-size +
    ResizeObserver) was removed with this change.

LOK SABHA 2024 RESULTS (seat share / vote share)
-----------------------------------------------
Owner's spec: only five groups -
    BJP                      bold orange, solid            (--bjp)
    BJP-aligned (NDA allies) light orange, diagonal hatch  (--nda, --nda-line)
    Congress (INC)           sky blue, solid               (--inc)
    Congress-aligned (INDIA) light blue, diagonal hatch    (--india, --india-line)
    Not aligned / others     green                         (--oth)
Group order everywhere (bar, data arrays, square filling) = LS_GROUPS =
    [bjp, nda, oth, india, inc]  -> NDA on the left, others in the middle,
    INDIA on the right (like Democrats left / Republicans right in the US).

UI (panel-loksabha):
  Tally: left NDA total (orange, check mark = won majority, hidden in vote
    view), centre Others (green, smaller), right INDIA total (blue). Under
    each: "BJP n · allies n" / "Congress n · allies n" (two lines under 520px).
  Bar: five segments in group order; hatched segments use CSS
    repeating-linear-gradient. Marker + "272 FOR MAJORITY" shown in seat view,
    faded out in vote view.
  .subtoggle (below the bar, above the map): small, quiet pill with
    "Seat share" / "Vote share" buttons (aria-pressed). Deliberately less
    prominent than the main race toggle.
  Map: each state's squares sorted left-to-right, column by column, then
    filled in group order with counts from LS[code].s (seat view) or
    LS[code].q (vote view). Fill = var(--bjp) / url(#hatch-nda) / var(--oth) /
    url(#hatch-india) / var(--inc); hatch patterns live in #map-india <defs>.
    Fill transitions .45s with a small delay by column (a left-to-right wipe).
  Legend: 5 swatches + a note that changes per view.
  Code: LS, LS_GROUPS, LS_NATIONAL, LS_RECTS, drawIndia, setLokSabha(mode).

Numbers (2024):
  Seats   BJP 240 | NDA allies 53 | others 16 | INDIA allies 135 | INC 99
          NDA 293, INDIA 234 (matches the official totals).
  Votes % BJP 36.56 | NDA allies 7.24 | others 13.73 | INDIA allies 20.29 |
          INC 21.19  (NDA 43.80, INDIA 41.48; NOTA 0.99 left out of the bar).
Vote-share squares (owner's rule): for each state, the five group shares
  (NOTA removed, re-normalised to 100) become squares by the largest-remainder
  method so the counts add up to the state's seats. States with 1 or 2 seats:
  all squares go to the group with the highest vote share (e.g. Goa 2 x BJP,
  Meghalaya 2 x others, Sikkim 1 x others because SKM's 43% is below
  CAP-S + SDF + independents at 51%).
  "Others" in a state = 100 - NOTA - (BJP + NDA allies + INC + INDIA allies),
  i.e. every party not in NDA/INDIA plus independents.

Data sources and how it was built (repeatable):
  1. Seats per party per state: the coloured summary bar in each state section
     of en.wikipedia.org/wiki/Results_of_the_2024_Indian_general_election
     (wikitext bold "PARTY (n)" cells). Bihar's CPI(ML) 2 seats had to be
     added by hand (brackets broke the regex). Check: each state sums to its
     seat count.
  2. Vote share per party per state: "2024 Indian general election in <State>"
     pages, rendered HTML via the MediaWiki parse API, read with
     pandas.read_html; pick the table whose "%"/"share" column has party
     abbreviations incl. BJP/INC and sums closest to 100. J&K's page picked a
     constituency table, so its values came from its alliance table:
     JKNC 22.30, BJP 24.36, INC 19.38, JKPDP 8.48, NOTA 0.67.
  3. National totals + alliance lists: "Results by party and alliances" table
     on the results page.
  Wikipedia rate-limits (HTTP 429): fetch with ~3s gaps and retry/backoff.
  The ECI results site (results.eci.gov.in/PcResultGenJune2024) is offline.
  Caveat: Wikipedia, not the ECI, is the source; spot-check before quoting.
Older elections: see LOK SABHA SEATS BY ELECTION for the state merges needed.


LOK SABHA SEATS BY ELECTION (2004-2024)
---------------------------------------
Every one of these elections had 543 elected seats. Per-state seat counts have
been frozen since 1977 (the 2008 delimitation redrew constituency boundaries
but did not change how many seats each state has). The only differences come
from states/UTs being split or merged:

  State / UT                    2004  2009  2014  2019  2024 (current map)
  Andhra Pradesh (undivided)     42    42    42     -     -
  Andhra Pradesh                  -     -     -    25    25
  Telangana                       -     -     -    17    17
  Jammu & Kashmir (incl. Ladakh)  6     6     6     6     -
  Jammu & Kashmir                 -     -     -     -     5
  Ladakh                          -     -     -     -     1
  Dadra & Nagar Haveli            1     1     1     1     -
  Daman & Diu                     1     1     1     1     -
  DNH-DD (merged 2020)            -     -     -     -     2
  Every other state / UT        same count in all five elections

Notes
  - Telangana was formed on 2 June 2014, after the 2014 vote, so 2014 results
    are for undivided Andhra Pradesh (42), though often reported as 25 + 17.
  - Ladakh became a separate UT in Oct 2019 (after the 2019 vote).
  - DNH and Daman & Diu merged in Jan 2020.
  - Jharkhand 14, Chhattisgarh 11, Uttarakhand 5 were created in 2000, so they
    (and Bihar 40, Madhya Pradesh 29, Uttar Pradesh 80) are the same in all five.
  - The 2 nominated Anglo-Indian seats (abolished 2020) were never part of 543.
  - Source: Claude's knowledge of Indian election history, not checked against
    an official source (Election Commission of India) - verify before
    publishing results.
How to draw an older election on this map:
  2019: merge J&K + Ladakh into one 6-seat block; DNH and DD as two 1-seat UTs.
  2004 / 2009 / 2014: as 2019, and also merge Andhra Pradesh + Telangana (42).


APPENDIX C: GEOGRAPHIC PACKING - TRIED AND REJECTED (kept for reference)
------------------------------------------------------------------------
Live briefly on 2026-10-09 (commit 6941717), then replaced: the owner prefers
the hand-made Figma layout. Method, in case real-geography packing is wanted:
Inputs: block shapes (Appendix A) + real state centroids (lat, lon):
    JK 33.6,74.9  LA 34.4,77.6  HP 31.9,77.2  PB 30.9,75.4  CH 30.73,76.78
    HR 29.1,76.1  DL 28.65,77.2 UK 30.1,79.2  UP 26.9,80.9  RJ 26.6,73.8
    GJ 22.7,71.6  MP 23.5,78.3  CG 21.3,82.0  BR 25.9,85.6  JH 23.6,85.3
    WB 23.8,87.9  OD 20.5,84.4  MH 19.4,76.1  TS 17.9,79.0  AP 15.9,79.7
    KA 14.7,76.2  GA 15.4,74.0  KL 10.4,76.4  TN 11.0,78.4  PY 11.9,79.8
    SK 27.5,88.5  AS 26.2,92.8  AR 28.0,94.5  NL 26.1,94.4  MN 24.7,93.8
    MZ 23.3,92.8  TR 23.7,91.7  ML 25.5,91.3  DD 20.6,72.9  LD 10.6,72.6
    AN 11.7,90.0 (pulled west from 92.7 so it is not miles offshore)
Target: t = K * (lon * 0.927, -lat), K = 2.0 squares per degree.
Constraints (hard): no two states' squares within one square of each other
    (Chebyshev distance >= 2); label box (measured text width at 15.7 SVG units,
    0.85 tall, centred one row above the top row) may not touch another state's
    squares, and labels keep 0.15 apart.
Cost (minimised):
    sum over state pairs within 10 degrees of
        w_ab * | (centre_a - centre_b) - (t_a - t_b) |^2
        w_ab = 1/(dist_deg + 1) * (n_a * n_b)^0.25      (keeps relative layout)
  + 3 * sum over real land neighbours of max(0, gap - 1)^2   (uniform 1 gap)
    Neighbour list: JK-LA JK-HP JK-PB LA-HP HP-PB HP-CH HP-HR HP-UK PB-CH PB-HR
    PB-RJ CH-HR HR-DL HR-UP HR-RJ DL-UP UK-UP UP-RJ UP-MP UP-CG UP-JH UP-BR
    RJ-GJ RJ-MP GJ-MP GJ-MH GJ-DD DD-MH MP-MH MP-CG CG-MH CG-TS CG-AP CG-OD
    CG-JH BR-JH BR-WB JH-WB JH-OD OD-WB OD-AP MH-TS MH-KA MH-GA GA-KA KA-TS
    KA-AP KA-KL KA-TN TS-AP AP-TN TN-KL TN-PY WB-SK WB-AS AS-AR AS-NL AS-ML
    AS-MN AS-MZ AS-TR AR-NL NL-MN MN-MZ MZ-TR
Search: start from the Figma arrangement spread out (x1.64) until legal, then
    simulated annealing (12,000 steps, T 20 -> 0): pick a block, shift it one
    square in one of 8 directions, pushing any blocks it collides with along
    (up to 8 blocks); accept by Metropolis rule. Ran several random seeds, kept
    the best (seed 5). Starting from a greedy placement instead gave wrong
    topology (Bihar above UP, Chhattisgarh below Odisha), so start from Figma.
Hand polish after the search (to close central voids): MP 2 left, CG 3 left
    and 2 up, JH 1 left, OD 2 left. Then labels checked in the browser.
A gravity term (pull to the centre) was tried and rejected: it moved Delhi above
    Haryana and dragged the Andamans inland.


APPENDIX A: HOW THE FIGMA BLOCK SHAPES WERE IMPORTED (repeatable)
-----------------------------------------------------------------
Use this to re-import after the owner edits the Figma frame, or to build a tile
map for another country the same way.
1. Figma frame: one child frame per state named "<CODE>-<slug> 1"
   (e.g. "UP-uttar-pradesh 1"); squares are ~78.7px with a ~82.87px pitch.
   get_metadata gives each state frame's bbox, but some state frames are
   flattened (no per-square children), so do not count squares from metadata.
2. get_screenshot of the frame at 1:1 (maxDimension = frame height, ~5329).
   Detect squares by colour (grey ~rgb(165,163,153) on a ~#e5e5e5 background)
   with connected-component labelling (scipy.ndimage.label); keep components
   taller than 20px. Expect exactly 543.
3. Assign each square to the state frame whose bbox contains its centre.
   Better: group squares into connected blocks (edge or diagonal neighbours,
   pitch < 1.2) and give each block the majority state of its clean (single-
   frame) squares. Blocks with no clean squares were named by position.
   Second import: J&K = 5 at the top, Uttarakhand = 5 squares east of Delhi
   (frame unnamed), Manipur = 2 inside the Assam frame, Goa = 2 left of
   Karnataka, Puducherry = 1 inside the Andhra frame, Andaman = lone square
   east of Tamil Nadu, Lakshadweep = lone square far left ("Frame 1660").
   Third import (same rules plus): Telangana's frame came through unnamed, so a
   block is only given its majority state when that state covers at least
   half the block; otherwise it is named by size/position (17 squares = TS,
   5 squares not at the top = UK). Never let 2 stray MH-frame squares claim TS.
   First import: J&K = the 5 at the very top, Goa = 2 squares
   left of Karnataka, Lakshadweep = lone square far left, Manipur = 2 squares
   overlapping the Assam frame, Meghalaya = 2 squares overlapping the WB frame,
   Bihar/W.Bengal squares in each other's frames go to their own block.
4. Convert px to square units (divide by 82.8681, subtract 0.5 for the corner).
   Per state, take the circular mean of the fractional x and y offsets, snap the
   squares to whole units around that offset, round to 0.01, then shift
   everything so the minimum x/y is 0.
   (This is exactly how the CURRENT India data was produced.)
5. Check: per-state counts (list above), total 543, then in the browser compare
   every <text> getBoundingClientRect against every rect and every other text
   (no overlaps), and that no label pokes outside the SVG.
Python used: a scratch venv with pillow, numpy and scipy.
